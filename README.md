# Ludo Royale

Multiplayer Ludo for a public Node.js Web Service.

## Render
- Build command: `npm install`
- Start command: `npm start`
- Use a Web Service, not a static site.

## Game
- 2–4 players
- Roll 6 to bring a pawn out
- Exact roll required to reach HOME
- Safe star squares cannot be captured
- Captures send an opponent pawn back to base
- Rolling a 6 gives another turn
- Three consecutive sixes forfeit the turn
- The first player to bring all 4 pawns HOME wins

The board is a true 15×15 Ludo layout: four 6×6 colored home quadrants, 52-square outer track, five-square colored home lanes, and a four-color center.
