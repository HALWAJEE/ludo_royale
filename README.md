# Ludo Royale v6.0.0

A polished multiplayer Ludo web game built with Node.js, Express and WebSocket.

## Deploy on Render

- Build command: `npm install`
- Start command: `npm start`
- Instance: Free is sufficient for hobby testing.

## GitHub files

Upload these files to the repository root:

- `index.html`
- `style.css`
- `app.js`
- `server.js`
- `package.json`
- `README.md`

## v6 polish

- Livelier game-table background and presentation
- More dimensional pawns with selectable glow rings
- Smooth per-square hop/landing animation
- Animated dice with shuffle/rattle sound
- Soft tactile movement sound on each pawn step
- Star landing chime and visual pop
- Capture notification sound
- Victory jingle
- Sound on/off control
- Responsive mobile and desktop game layout

Audio is generated with the browser Web Audio API, so no external audio assets are required.


## v12 additions
- Common in-game chat with rate limiting and HTML-safe text handling.
- Compact floating dice/roll dock so players can roll without scrolling away from the board.
- Mobile chat drawer and desktop chat panel.
